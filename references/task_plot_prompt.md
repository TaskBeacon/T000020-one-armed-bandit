# Task Plot Prompt

Create a clean scientific task-flow timeline on a white background with a blank top header band reserved for later overlay. Do not draw any title, subtitle, logo, watermark, people, device, lab room, or decorative scene.

Use four horizontal rows:

1. Block 1: L 75% / R 25%
2. Block 2: L 25% / R 75%
3. Block 3: L 65% / R 35%
4. Block 4: L 35% / R 65%

For every row, draw the same left-to-right sequence with arrows:

1. Fixation
   - Screen: fixation cross.
   - Timing: 500 ms.
   - Response label: no response.
2. Bandit choice
   - Screen: two option panels labeled Left bandit and Right bandit.
   - Add the row-specific probabilities as small labels above or inside each option.
   - Timing: 2500 ms.
   - Response label: press F(left) / J(right).
3. Confirmation
   - Screen: selected option highlighted.
   - Timing: 400 ms.
   - Response label: no response.
4. Outcome feedback
   - Screen: reward +10 or no reward +0, with running total.
   - Timing: 800 ms.
   - Response label: no response.
5. ITI
   - Screen: fixation cross.
   - Timing: 600 ms.
   - Response label: no response.

Keep all text readable. Use compact boxes, clear arrows, and consistent spacing. The content should fit four rows under the reserved header band.
